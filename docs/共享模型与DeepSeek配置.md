# 共享模型与 DeepSeek 配置

2026-10-16 用户已调整需求：所有登录成员共用管理员提供的 DeepSeek API Key，不要求个人 Key。真实 Key 仅配置在当前电脑的后端，不通过 GitHub 或网页分发。这取代原来的个人 Key 管理方案。

## 工作方式

浏览器登录后只获取共享服务是否配置、受控模型能力和连接测试结果。后端从 `DEEPSEEK_API_KEY` 读取凭据，再携带凭据请求固定的 DeepSeek 官方接口。普通成员无需填写 Key，管理员网页也看不到明文或掩码；页面没有保存、替换、删除 Key 的入口。

共享的是服务凭据，笔记、会话和文件的私人所有者权限保持有效。后续模型生成的费用由这个 DeepSeek 账户承担。共享配置、能力表、文字生成、SSE、取消与私人历史已完成本机验收，见 [文字对话与运行恢复](AI文字对话与运行恢复.md)。PDF 选页、整本提问与原页引用也已接通，见 [PDF对话说明](PDF选页与整本AI对话.md)；回答保存为可编辑笔记及来源回看也已实现，当前边界见 [M1 开发与云端验收计划](M1开发与云端验收计划.md)。

## 本机配置

当前 API/Worker 原生运行，读取 `backend/.env` 中的 `DEEPSEEK_API_KEY`。该文件由 Git 忽略，真实值不进入源代码、文档、测试、Docker 构建上下文或前端构建。

本次已按用户授权使用其提供的 Key 写入这个本机配置，重启 API 和 Worker，并通过网页执行一次真实模型列表连接测试。此 Key 未写入根目录 Docker `.env`、服务器 `.env.server` 或 GitHub Secrets。

日后更换或删除 Key 时，只在这台电脑修改私密配置，然后重启 API/Worker。不要把 Key 配置成 `VITE_` 变量；Vite 环境变量可能进入浏览器构建。也不要把完整配置文件、进程环境或请求头打印到日志、聊天或截图。

`DEEPSEEK_API_KEY` 允许为空：笔记和账户功能正常，模型页面显示尚未配置，管理员连接测试返回 503。非空值需为 16–512 个可见 ASCII 字符；格式错误时启动失败，错误信息不回显值。

访问 `http://localhost:5173` → “模型设置”。所有成员看到共享服务状态和模型能力，只有管理员能点击“测试连接”；成员直接请求测试接口也会被后端拒绝。

## 密钥的保存和传输范围

- 本机后端配置和运行进程需要持有 Key；浏览器不持有 Key，也不向成员返回末四位。
- 后端仅在请求 DeepSeek 时，通过 HTTPS 把 Key 发送给 `api.deepseek.com`。Key 不写入业务数据库或操作审计。
- 此次没有复制配置到服务器。将来若让用户通过另一台服务器使用模型，需要明确将凭据另行配置到该服务器，或让服务请求继续经过持有凭据的本机后端。
- 本机配置应随其他私密配置保密备份；不要将它包含在公开代码压缩包或共享文档中。

## 连接测试与模型能力

`GET /api/v1/ai/providers` 需要登录，仅返回 `credential_source: shared`、是否配置和受控能力表。`POST /api/v1/ai/connection-test` 需要管理员身份、CSRF 和正确 Origin，不接受浏览器提供的凭据作为调用来源。

连接测试仅向 `https://api.deepseek.com/models` 发送一次 GET，不发送笔记、不生成回答、不自动重试、不跟随重定向，不使用环境代理或自定义地址。响应有大小限制和连接/读取超时，结果只保留受控模型 ID；服务商返回的错误正文不转发给浏览器。等待服务商时释放账户锁，返回前重新验证会话、停用状态和管理员权限。

截至 2026-10-16，受控能力依据 [DeepSeek 官方模型说明](https://api-docs.deepseek.com/quick_start/pricing) 和 [模型列表接口](https://api-docs.deepseek.com/api/list-models)：

| 模型 ID | 文字 | 图片 | 流式 | embedding |
|---|---|---|---|---|
| `deepseek-flash` | 支持 | 支持 | 支持 | 不支持 |
| `deepseek-v4-pro` | 支持 | 不支持 | 支持 | 不支持 |

本次真实模型列表测试成功，确认这两个模型 ID 可见。这不能代替实际文字/图片生成、余额或生成质量验收。网页“本次连接验证”只保留当前页面操作的结果，刷新后可重新手动测试，不在后台自动调用服务商。
