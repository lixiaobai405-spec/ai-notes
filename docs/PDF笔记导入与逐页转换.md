# PDF 笔记导入与逐页转换

2026-10-16 按用户确认，先补齐 PDF 输入，再进行 T12 实际 AI 对话。一份 PDF 创建一篇多页图片笔记，保留原始文件；转换不使用 DeepSeek 或其他模型 API。

## 网页使用

1. 登录后进入“我的笔记”，在列表上方找到“导入 PDF 笔记”。如当前正在阅读笔记，先点击“返回笔记列表”。
2. 选择 PDF，点击“导入并转换 PDF”。标题默认使用文件名；列表中已选择的笔记本和标签会作为导入目标。
3. 上传完成后进入笔记，显示“等待后台转换 / 正在逐页转换”和已完成页数。刷新、关闭页面或切换笔记不影响后台任务。
4. 已完成页面可以先阅读，全部完成后可调整页序、追加图片或修改笔记信息。阅读器支持页码选择、缩放和拖动。
5. 点击“下载原始 PDF”可下载原件。只有笔记本人能够读取源文件和页面；管理员不绕过私人所有者权限。

本机已保留一篇三页“PDF导入验收样例”，包含中文、公式和图形，可直接打开试读。样例由程序生成，没有使用用户私有笔记。

## 默认范围

| 项目 | 默认 |
|---|---|
| 单份 PDF | 大于 0，最多 50 MiB |
| 页数 | 1–200 页 |
| 同时待完成的导入 | 每人最多 10 份 |
| 上传等待 | 至少允许 300 秒；仍校验实际大小和声明一致 |
| 单次打开/单页转换 | 最长 60 秒，超时终止渲染子进程 |
| 页面分辨率 | 200 DPI，长边最多 3200 像素，并受现有像素/单图字节限制 |
| 页面存储 | JPEG 原页面 + 现有阅读图、缩略图；原 PDF 完整保留 |

源 PDF 和生成的页面原图均计入用户的文件容量额度。现有 `STORAGE_QUOTA_BYTES` 仍控制原文件总容量，阅读图和缩略图沿用现有派生图策略。极端尺寸、损坏、需要密码、过多页或超额的文档会给出明确原因，已完成的页不会因为后续页失败而丢失。

输入加密 PDF 时，页面提示先在本机解锁后重新导入；网站不接收或保存 PDF 密码。PDF 已成为图片页面，全文检索/OCR 和实际 AI 对话仍待后续阶段。

## 失败与恢复

- 上传中断：在原来的笔记中重新选择同名 PDF 继续。源文件未确认前会校验字节数与已接收内容；过期的上传可以重新激活，不新建第二篇笔记。
- 后台临时故障：复用持久任务队列和租约，自动退避重试，最多三次；重试从 `completed_pages` 继续。
- 重试耗尽：页面提供“重试未完成页面”，仍使用同一导入和笔记；完成过的页面不会重复插入。
- 损坏、密码、页数或容量限制：提示具体原因并保留源文件。可下载原件处理后重新导入，或将失败笔记移入回收站。
- 转换中删除笔记或停用账户：停止发布新页面；恢复笔记/账户后可重试未完成部分。已删除笔记的旧文件链接也不可读取。

转换期间暂时锁住图片上传和页序调整，防止原页序与手工操作交叉。每页的文件、变体、页记录、进度和笔记版本在同一个租约校验事务中提交。提交回执丢失时，不会误删已经入库的页面对象；数据库不可确认时保留不确定对象，后续恢复/清理时再处理。

## 运维与配置

新增依赖锁定 `pypdfium2==5.14.0`，使用其 PDFium 渲染引擎。PDFium 不允许并发线程调用，因此每份任务在独立、可终止的子进程中顺序渲染，主 Worker 负责租约续期和入库；参考 [官方 Python API 的线程说明](https://pypdfium2.readthedocs.io/en/stable/python_api.html)。

部署先备份数据库，在 `backend` 更新锁定依赖并执行：

```bash
uv sync --locked
uv run alembic upgrade head
uv run alembic check
```

迁移 `d89f74a2136c` 接续 `c2e41a9f3b67`，只新增 `pdf_imports` 表，复用现有文件、上传会话、笔记页与任务表。不要在有导入记录的环境直接 downgrade，降级会删除导入来源和进度关系。

完成后重启 API 与 Worker，前端重新构建。API 和 Worker 必须使用相同的私有存储配置。只运行 API、没有 Worker 时，任务会停在“等待后台转换”。Caddy 的现有反向代理沿用，无需增加公共文件目录。

| 配置 | 默认与说明 |
|---|---|
| `PDF_MAX_BYTES` | `52428800`，源 PDF 最大字节数 |
| `PDF_MAX_PAGES` | `200`，最高允许配置到 500，与现有页序接口上限一致 |
| `PDF_PAGE_TIMEOUT_SECONDS` | `60`，文档打开和每页渲染的期限 |

网页说明按默认 50 MiB/200 页展示；修改部署上限时，应同步调整网页校验和文案。无需模型 Key 或额外 Redis 服务。当前本机已备份、迁移和重启，尚未部署到 ECS。
