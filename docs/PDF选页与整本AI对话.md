# PDF 选页与整本 AI 对话

2026-10-16：在已有共享 DeepSeek 文字对话上增加 PDF 选页与整本提问，所有登录成员无需个人 Key，私人对话、PDF 与页图仍按所有者隔离。

## 使用方式

1. 在“我的笔记”导入 PDF，等待全部页面转换完成。
2. 打开“AI 对话”，新建对话，在“本次资料”选择 PDF 笔记。
3. 选择“指定页”，输入如 `2、4-6`；或选择“整本 PDF”。页面显示实际范围、批次数与计划模型调用次数，然后发送问题。
4. 查看已完成读取的页数、当前阶段和回答。点击回答中的页码打开原页，也可展开“本次资料”查看所选原页。原页阅读器支持缩放、拖动及返回对话。
5. 完整成功的回答可点击“保存为笔记”，确认标题与笔记本。保存直接使用已有结果，不再调用模型；笔记保留本轮问题、回答、模型、PDF 名称与原页码，并在独立来源区域提供原页入口。重复保存不覆盖后续编辑，也不重建回收站笔记，详见 [回答保存说明](AI回答保存为笔记.md)。

PDF 使用支持图片的 DeepSeek Flash。选择 PDF 后，模型列表不提供仅文字的 Pro；直接绕过网页提交 Pro 也会被后端拒绝。更换 PDF 请新建对话，一段对话只能关联同一本 PDF。

刷新或切换页面不会重新创建生成请求。来源范围和结果保存在数据库，历史对话会恢复最近一轮的 PDF 选择。文字历史仍参与多轮上下文；历史页图不会自动全部再次发送，只发送本轮明确选择的页图。

## 原页码与引用

`note_pages.pdf_page_number` 保留原 PDF 的页码，不随笔记排序改变；后来上传到这篇图片笔记里的普通图片没有这个编号，不会混入“整本 PDF”。已有导入记录在迁移时从最早包含全部已转换页的服务器版本快照恢复映射，不依赖文件名或当前页序。缺少可靠映射时拒绝调用，提示重新导入原件。

运行冻结来源笔记 ID、标题、版本、原页码、page_id、file_id 与私有阅读图对象。只有后端内部保留对象键；API/SSE 只返回经过筛选的安全来源信息。引用使用 `[[p:N]]`，前端只将本轮所选的合法页码转为按钮，不把模型生成的任意 URL 当来源链接。

打开原页先检查运行所有者、来源笔记未删除、冻结的页与文件关系仍有效，再使用现有的认证图片读取流程。来源笔记更新时提示引用来自历史版本；原页身份不会变成排序后的另一张图。管理员也不能绕过其他用户的所有者检查。

## 整本与分批处理

每批最多 8 页，阅读图原始字节合计最多 12 MiB。单批可直接看图回答；多批先逐批读取，每批形成保留原页码的阅读记录，再综合回答。阅读记录超过 4 组时，每最多 4 组合并一层，直到最后一轮综合的输入受控。

例如 9 页通常使用 2 次看图读取和 1 次文字综合；200 页小图在页数分批下为 25 次读取、8 次逐层整理、1 次最终回答，共 34 次。页图体积较大时会拆成更多批，预览返回实际调用计划。整本模式会向模型提供全部选定页图；综合结果属于分批概览，不能当作逐字转录或无遗漏的全文 OCR。

页图由后端从现有私有存储读取，通过 HTTPS 以内嵌 JPEG 发送到固定 DeepSeek 地址，不创建公开图片链接，不使用服务商 Files API 留存文件。后端不把 base64 页图或共享 Key 存入运行的文字上下文。

## 限制与费用

- PDF 最多 200 页，须已完整导入；单张阅读图最多 8 MiB，本次所选阅读图总量最多 128 MiB。超出时发送前报错，可选择更少页。
- 已有文字上下文限制 32000 UTF-8 字节；每组汇总参考记录最多 70000 字节；每次模型请求体最多 24 MiB。这里是应用自己的保守预算。
- 阅读/整理每次最多输出 2048 tokens，最终回答最多 4096 tokens。阅读记录被截断时停止后续综合，明确标记未完成，不声称已读完整本。
- 每位用户同时一条在途运行、每小时最多 30 次创建运行。一个整本运行可以包含多次付费调用，预览显示的计划次数应在发送前查看。
- 用量对各次调用已返回的 token 统计求和。部分调用没有返回最终用量时，网页显示“已知用量”和未完整返回提示，不推算精确账单。

当前仍是单 Worker，与 PDF 转换和图片处理串行执行。大 PDF 会等待并占用处理时间，本阶段没有大规模并发承诺。共享 Key 仍只在本机后端私密配置中，没有复制到云端。

## 中断、取消和来源失效

新增 `ai_steps`，每次模型 POST 前提交 running 阶段记录。阅读记录、部分最终回答、已完成页数与用量持续保存。步骤只有一次尝试；未知外部结果、网络断线、崩溃或租约失效不会触发自动重发。已完成的内部阅读记录保存在数据库，本阶段还没有让用户在失败后自动复用它们的续跑功能；重新发送是用户主动创建新运行，会重新处理所选资料。

“停止生成”保存取消状态，Worker 在下一次检查时关闭当前上游连接并停止后续批次；等待服务商数据时受现有 20 秒读取超时约束。已产生的费用不能撤回。已读进度按完整成功的批次计算，当前批收到部分内容但未完整结束时不会算作已完成读取。

每次模型调用前重新验证来源，生成检查点也检查账户与笔记存活状态。删除笔记、账户停用或页图身份失效后，停止继续调用；包含已删除 PDF 的历史也不会被转发到下一轮模型。回答记录仍属于用户自己的私人历史，来源按钮会明确报不可用。

迁移 `63b9d8343e02` 为 note_pages 增加原 PDF 页码，为 ai_runs 增加冻结来源和进度，并创建 ai_steps；保留旧笔记、旧会话与原件。新接口：

| 接口 | 用途 |
|---|---|

SSE 的 state 事件新增 progress，meta/done 继续携带经过过滤的来源与完整状态。写请求仍验证 CSRF 和 Origin。
